# CopperTrace

Independent electronics, embedded systems and reverse-engineering notes.

This repository contains the source for **coppertrace.co.uk**.

## Stack

- Astro
- Static HTML/CSS
- Cloudflare Pages
- GitHub

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Cloudflare Pages build command: `npm run build`  
Build output directory: `dist`
